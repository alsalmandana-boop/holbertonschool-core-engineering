# Holberton School - Core Engineering

## Description

This repository contains projects and exercises completed as part of the
Holberton School Core Engineering curriculum.

The projects focus on building fundamental programming and software
engineering skills, including Python syntax, control flow, data structures,
functions, modules, development environments, and problem-solving.

## Projects

### Python Fundamentals

The `python_fundamentals` directory contains introductory Python projects
covering the core concepts of the language.

Topics include:

- Python interpreter and script execution
- Variables and formatted output
- Virtual environments and package management
- Conditional statements
- Loops and iteration
- Lists, tuples, sets, and dictionaries
- Functions and return values
- Modules and imports
- ASCII manipulation
- PEP 8 coding style
